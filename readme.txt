FANZAアフィリエイト記事を自動投稿し、高度なSEO最適化を実現するWordPressプラグイン。

== 説明 ==

FANZA SEO Autoposter は DMM Web API v3 を利用して、FANZAアフィリエイト記事を
自動投稿するプラグインです。SEO最適化・AIリライト・CTR分析など販売サイト運営に
必要な機能を一括提供します。

=== プラン別機能 ===

**Free（無料）**
* DMM Web API v3 連携（全フロア対応）
* 投稿スロット 1本
* WP-Cron による時間指定自動実行
* テンプレート変数タグ（[title][actress][genre] など30種類以上）
* 重複投稿の自動スキップ
* アイキャッチ画像の自動ダウンロード
* JSON-LD 構造化データ / OGP / Twitter Card / 画像サイトマップ

**Pro（月額 6,800円）**
* 投稿スロット 4本
* 投稿時間ランダム化
* セール品フィルター
* API説明文スクレイピング（GraphQL対応）
* メタディスクリプションテンプレート

**Premium（月額 12,800円）**
* 投稿スロット 8本
* ランキング記事自動ビルダー（週次/月次）
* ランキングテンプレート変数システム
* コラージュアイキャッチ自動生成（GD）
* 順位変動バッジ（▲N/▼N/NEW）
* セール検知＆自動リライト
* ジャンル別テンプレート
* CTR分析ページ（PV/クリック/CTR）・CSVエクスポート
* AI自動リライト（OpenAI / Anthropic Claude 対応）
* 投稿履歴ページ
* エラー通知メール

== インストール ==

1. プラグインフォルダを /wp-content/plugins/ にアップロード
2. WordPress管理画面 > プラグイン から有効化
3. 管理画面 > FANZA Autoposter > API設定 で DMM API IDとアフィリエイトIDを入力
4. 管理画面 > FANZA Autoposter > ライセンス でライセンスキーを認証
5. 管理画面 > FANZA Autoposter > 投稿スロット1 で投稿設定を行う
6. 管理画面 > FANZA Autoposter > 自動実行設定 で実行時間を設定してONにする

== テンプレートの作成方法 ==

1. 新規投稿 > タイトルを「FAP テンプレート」（スロット2以降は「FAP テンプレート2」など）
2. 本文に変数タグを使って記事テンプレートを作成
3. ステータスを「下書き」で保存

== よくある質問 ==

= APIキーはどこで取得しますか？ =
DMM.com アフィリエイト会員ページ > ツール > APIを利用する から取得できます。

= サーバーへの負荷は大きいですか？ =
API取得・画像ダウンロードを伴うため、大量投稿時はサーバー負荷が上がります。
1スロット1〜20件程度に留めることを推奨します。
